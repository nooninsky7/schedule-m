# Schedule-M (모바일 스케줄 & 루틴 매니저)

스마트폰에서 24시간 간편하게 관리하는 공부, 수면, 운동, 할 일 통합 스케줄러 웹앱입니다.

- **접속 주소**: https://nooninsky7.github.io/schedule-m/
- **주요 기능**:
  - 📖 **공부 시간 관리**: 시간(시/분) 간편 입력 및 주단위/월단위 달성 통계
  - 🌙 **수면 시간 관리**: 수면 시간 입력 및 7시간 달성/부족 기준 자동 분석
  - 🏃 **운동 관리**: 간편 운동 기록 및 활동 시간 관리
  - 📅 **달력 보기**: 일/주/월별 루틴 달성 현황을 커다란 달력에서 한눈에 확인
  - 📱 **모바일 최적화**: 스마트폰 세로 화면 및 홈 화면 바로가기(PWA) 지원
